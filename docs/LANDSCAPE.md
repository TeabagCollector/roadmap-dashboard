# Related tools

This is a small first-party-source comparison, not an exhaustive market survey or a hands-on quality evaluation. No third-party app was installed and no competitor code/assets were copied.

| Project | What its own documentation describes | Relationship to this preview |
| --- | --- | --- |
| [jstarfruits/AgentDock](https://github.com/jstarfruits/AgentDock) | Native macOS menu bar and floating panel for Claude Code, Codex and VS Code; live/waiting states, English/Japanese | Very close in form and session overview. Its README explicitly focuses on mission control rather than task management; our focus includes persistent expandable roadmaps and acceptance. |
| [thomas-scrace/mission-control](https://github.com/thomas-scrace/mission-control) | Local web dashboard organized around projects and worktree slots, agent state, next steps and optional model synthesis | Broader developer/worktree management. Our current design is a compact native companion and deterministic core; its synthesis is configurable/optional, so do not claim it inherently requires a model. |
| [zuuzii-org/llm-pulse](https://github.com/zuuzii-org/llm-pulse) | Native macOS panel, local Codex/Claude Code/ZCode adapters, notifications, usage, English/Chinese switching | Confirms both native and bilingual monitoring already exist. Its README says completed work is primarily notifications; this preview keeps durable task roadmaps and acceptance evidence. |
| [Codex Mission Control — VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=kolling88.codex-mission-control) | VS Code extension for Codex parent chats/subagents, states, workspace and usage | A genuine editor plugin. This project is a standalone macOS companion, not an official Codex or ChatGPT extension. |

Multiple unrelated products use the name AgentDock or Mission Control. Links above identify exact repositories; the native profile manager `euforic/AgentDock`, the commercial site `agentdockapp.com` and other AgentDock services should not be conflated with `jstarfruits/AgentDock`.


Dashboard for Codex focuses on the ChatGPT Desktop workflow and persistent roadmaps. Similar monitoring tools already exist; no uniqueness claim is made.
